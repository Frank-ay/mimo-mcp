# 启动说明

本项目有三个可启动产物:**Web 控制台**(后端 :7801 + 前端 :5173)与 **stdio MCP server**(给 Claude Code / Codex 调用)。下面是从零到跑起来的具体命令。

## 0. 前置依赖

- Python 3.11+ 与 [uv](https://docs.astral.sh/uv/)
- Node 22+ 与 pnpm

## 1. 安装依赖(首次)

```bash
uv sync                                         # 后端 Python 依赖
cd webui/frontend && pnpm install && cd ../..   # 前端依赖
```

## 2. 配置 API Key(首次)

```bash
cp .env.example .env
# 编辑 .env:把 MIMO_API_KEY 改为真实 key;Token Plan 套餐(tp- 开头)还需设 MIMO_BASE_URL
```

## 3. 启动

### 方式 A:一键开发(推荐)

```bash
./scripts/dev.sh
```

一条命令同时拉起后端 + 前端,按 `Ctrl+C` 一起停。它实际等价于**并行执行**这两条:

```bash
./scripts/run_web.sh             # 后端:自动 source .env → uv run --quiet mimo-web → http://127.0.0.1:7801
cd webui/frontend && pnpm dev      # 前端:vite,/api 代理到 :7801 → http://127.0.0.1:5173
```

启动后打开 <http://localhost:5173> 即可看到控制台。

### 方式 B:分两个终端(等价于方式 A 手动版)

```bash
# 终端 1 — 后端
./scripts/run_web.sh

# 终端 2 — 前端
cd webui/frontend && pnpm dev
```

### 方式 C:生产 / 单进程

```bash
./scripts/build_frontend.sh      # =(按需 pnpm install)+ pnpm build → 产出 webui/frontend/dist
./scripts/run_web.sh             # FastAPI 自动托管 dist
```

只跑后端一个进程,访问 <http://localhost:7801> 一个地址即可。

### 方式 D:stdio MCP server(给 Claude Code / Codex)

```bash
./scripts/run_mcp.sh             # 自动 source .env → uv run --quiet mimo-mcp(stdio,不监听端口)
```

非交互式,由编程工具按 MCP 协议调起,不用浏览器访问。注册方式见 [README](../README.md) §3。

## 4. 验证

```bash
# 后端健康检查(不消耗 token)
curl -s http://127.0.0.1:7801/api/usage/health | python3 -m json.tool

# 前端
curl -s -o /dev/null -w "%{http_code}\n" http://127.0.0.1:5173/
```

后端健康正常时 `api_key_configured / base_url_reachable / auth_valid` 均为 `true`。

## 5. 停止

- 用 `dev.sh` 或单终端启动的:在该终端按 `Ctrl+C`(`dev.sh` 会同时停掉前后端)。
- 后台启动的:`lsof -ti:7801,5173 | xargs kill`

## 附:脚本 → 底层真实命令对照

| 脚本 / 命令 | 实际执行 | 端口 / 产物 |
|---|---|---|
| `scripts/dev.sh` | `run_web.sh` + 前端 dev 并行,统一 `Ctrl+C` 退出 | :7801 + :5173 |
| `scripts/run_web.sh` | `source .env` → `uv run --quiet mimo-web` | :7801 |
| `scripts/run_mcp.sh` | `source .env` → `uv run --quiet mimo-mcp` | stdio |
| `scripts/build_frontend.sh` | `cd webui/frontend` →(按需 `pnpm install`)→ `pnpm build` | webui/frontend/dist |
| 前端 dev(`pnpm dev`) | `vite` | :5173 |
| `uv run mimo-web` | `webui.backend.main:main`(FastAPI / uvicorn) | :7801 |
| `uv run mimo-mcp` | `mimo_mcp.server:main`(FastMCP,stdio) | stdio |
